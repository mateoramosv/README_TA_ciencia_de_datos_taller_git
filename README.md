## Caracteristicas de los proyectos liderados y ejecutados por un científico de datos
Un proyecto de ciencia de datos bien elaborado no consiste solo en tener una gran cantidad de datos de calidad, debe cumplir con varias cuestiones y caracteristicas que todo científico de datos debe tener en cuenta a la hora de trabajar en un proyecto

| | **Característica** | **¿Qué queremos decir?** |
|---|---|---|
|1| Parte de un problema real | El proyecto debe nacer de una necesidad concreta de una persona o organización, el cientifíco de datos no construye proyecto porque si o por analizar grandes cantidades de datos, debe haber una razon de ser del proyecto |
|2| Tiene una pregunta clara | Se define qué se busca responder con los datos que tenemos, si tenemos una pregunta clara sabremos a donde debe encaminarse el proyecto, en cambio si no tenemos una pregunta clara podremos trabajar con los datos sin llegar a nada|
|3| Usar datos confiables | Se debe saber de donde se tomaron los datos y se deben limpiar para mejorar su calidad, e incluso actualmente en el tiempo de la IAG podemos tener grandes bases de datos generadas y entra la pregunta ¿Que tan etico es para un cientifico usar esos datos? !
|5| Entender lo que se hace, el cientifico de datos no solo debe saber manejar los datos, debe poder entender el contexto para saber que estan diciendo sus analisis sobre el mundo real |
|6| Comunicación clara | Se debe poder comunicar claramente al mundo lo que se esta haciendo, un cientifico de datos debe tener conocimientos tecnicos pero debe ser capaz de explicar los resultados de su analisis a cualquier persona |
|7| Termina en algo util | Un proyecto de un cientifico de datos debe cumplir su cometido, ser util y eficiente en la vida real, es preferible asumir incertidumbre y tener un modelo eficiente |

> [!NOTE]
> Estas características las construimo a partir de lo visto en clase y de la experiencia de cientificos como John Foreman (Presentación realizada por compañera de nuestro grupo)
